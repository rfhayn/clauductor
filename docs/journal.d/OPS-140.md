## Decisions

- #269.2 moved the check rather than rewording the docs. "Stop before anything changes" is the behaviour the docs promised, and `install.CheckEnabled` is the one place both callers use.
- The owner approved round 4's redesign (2026-10-28), past the review cap of 3. Round 3 still found git that the per-spelling source scan missed. The scan grew a rule for each spelling review named, and review kept finding another. The strip in every test binary's `TestMain` closes the class at its authority: every process a test starts inherits from it. The guard then checks one thing per package. The spelling scanner, `signals.EnvRunner` and `testgit.Shim` were deleted, and the 58 runner sites went back to `signals.ExecRunner`.
- `testgit.Command` and `testgit.Env` stay. Command gives the 25 fixture sites one helper, with a commit identity and the git found before any test stubs PATH. Env keeps dropping `GIT_` variables, for a test that sets its own as a hook's stand-in (template's `TestTheFixturesGitStaysInTheFixture`).
- `treesnap` is exempt from the TestMain rule because `testgit` imports it (for `Outer`). The guard holds its tests to running no git.
- `Outer` excludes one thing from its whole-tree comparison: the `.git` directory's own mtime. `git status` takes `.git/index.lock` to refresh the index and then removes it, which moves only that.
- #274 left `rewrite.go` unchanged. The rewrite passes no case-arm form, and the detector now reports the new shape, so a template line using it fails the build instead of shipping an empty `CLAUDUCTOR_FW`.
