## Decisions

- #269.2 moved the check rather than rewording the docs: "stop before anything changes" is the behaviour the docs promised, and `install.CheckEnabled` is the one place both callers use.
- #281/#302 got a shared package instead of `cmd`'s `gitFreeEnv`, which lives in a test file no other package can import. A source scan closes the class, because a behavioural guard per helper would cover only the helpers someone remembered. `cmd`'s `gitFreeEnv` stays for the CLI helper processes, which are not fixture git.
- #274 left `rewrite.go` unchanged. The rewrite passes no case-arm form, and the detector now reports the new shape, so a template line using it fails the build instead of shipping an empty `CLAUDUCTOR_FW`.

## Surprises

- The first demonstration of the PersistentPreRun test passed when it should have failed: `doctor` sets `SilenceUsage` itself, so a hook on it changes nothing. `init` showed the failure.
- The scan found 25 direct git calls in test files, well beyond the three #302 named. That includes `lanes`, `web`, `install` and `lease` helpers built on `os.Environ()`.
- Review found the class larger again in each round. In round 1 it was the panel's own git through `signals.ExecRunner` (58 sites). - `testgit` cannot offer the runner itself: it would import `signals`, which imports `brand`, whose tests import `testgit`, a cycle. So the runner is `signals.EnvRunner`.
