## How This Works

- **This file** is a hub/index — it stays small and points to active milestone files
- **`docs/next-prompt-PREFIX-#.md`** files hold per-milestone implementation guidance
- File name matches your milestone ID (e.g., `next-prompt-AUTH-1.md` or `next-prompt-AUTH-1.3.md`)
- `/new-milestone` creates the branch-specific file and adds a pointer here
- `/milestone-complete` removes the pointer and deletes the branch-specific file
